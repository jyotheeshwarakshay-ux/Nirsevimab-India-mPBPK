# Nirsevimab India-Specific mPBPK-QSSA-TMDD Model

India-specific pharmacometric model for nirsevimab in Indian infants using real IAP 2015 LMS growth charts, QSSA-TMDD, viral escape dynamics, and Monte Carlo PTA (90.5%).

**Key outputs:**
- PTA = 90.5% (n=5,000 virtual Indian infants)
- Full R code + Shiny dosing simulator
- Open-source for translational immunopharmacology
